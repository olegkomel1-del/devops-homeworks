## Задание: Шифрование бакета с помощью KMS

### 1. Создание ключа KMS
Был создан симметричный ключ в сервисе Key Management Service с именем `bucket-key` (ID: `key-1793830917048`).

### 2. Шифрование бакета
В настройках бакета `test-bucket-komel` (вкладка «Безопасность» → «Шифрование») был выбран созданный ключ KMS. Теперь все новые объекты, загружаемые в бакет, будут автоматически шифроваться.
